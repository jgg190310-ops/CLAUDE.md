Salvar na Nuvem (Firebase)

1 Acesse console.firebase.google.com e crie um projeto gratuito
2 Em Realtime Database, crie o banco e copie a URL (termina em .firebaseio.com)
3 Em Configurações > Seus apps, copie o trecho firebaseConfig e cole abaixo
4 Em Authentication > Sign-in method, ative Anônimo
5 Em Realtime Database > Regras, cole as regras abaixo e publique 
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "$uid === auth.uid",
        ".write": "$uid === auth.uid"
      }
    }
  }
}
